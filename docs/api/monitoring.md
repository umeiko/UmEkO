# 管理员资源监控

登录独立管理端，在顶部选择“资源监控”。页面每 5 秒读取一次数据，保留最近约 10 分钟趋势；切换到其他页面、隐藏浏览器标签或退出后停止轮询。

| 指标 | 测量范围 |
| --- | --- |
| 服务器 CPU | UMEKO 所在机器的总体 CPU 使用率与逻辑核心数 |
| 服务器内存 | 整台机器使用量、总量、使用率 |
| 数据所在磁盘 | 数据目录所在卷的已用、可用与总容量，不是 UMEKO 目录单独占用 |
| UMEKO 进程 | 主服务进程的 RSS 内存、CPU、线程数；进程 CPU 100% 约等于占满一个核心，可能超过 100% |
| 服务状态 | 网页会话、机器工作区、内存会话、Run 状态、数据库与 WAL 文件字节数 |
| 模型队列 | 每模型并发上限、正在调用、等待调用 |
| 机器任务 | 状态数量、任务 Worker / 队列 / 调用者容量、保留时间，最近 100 个任务、所属 Agent、调用者、来源 IP 及停止按钮 |

GPU 不在当前监控范围。远端模型服务器的 GPU、显存和模型平台流量需在 LiteLLM 或模型提供方监控中查看。容器部署时 psutil 的主机 / 容器可见范围与平台有关，不应把这些读数直接当作 cgroup 配额使用率。

“服务接入”可切换需要凭据 / 免鉴权，保存后立即生效并跨重启保留；还可创建、停用、更换机器凭据和删除服务账号。凭据只显示一次；列表只含名称、权限、状态与到期时间。删除账号会清理它的任务与文件历史，未结束任务需先停止。管理员停止任务使用共享取消机制，不会强制终止整个服务。说明文字收在圆圈问号中，悬停或聚焦查看，手机上可点击查看。

免鉴权调用显示为“免鉴权调用”，共用任务身份；IP 只用于记录，不作鉴权。未知 IP 和升级前的任务显示“未知”。带凭据的调用仍显示服务账号名称。

“服务接入”下的“智能体管理”统一维护每个 Agent 的介绍、工作指引、默认模型和 Skill 选择。点击“配置与入口”查看独立地址与只读 Card 预览。任务列表显示所属 Agent，便于确认哪个服务在使用共享资源，见[智能体管理](agents.md)。

API：

| 方法 | 管理端口路径 | 返回 |
| --- | --- | --- |
| GET | `/admin/v1/resources` | `current`、`history`、`interval_seconds` |
| GET / PUT | `/admin/v1/service-access` | 接入方式 `auth_mode`：`required` 或 `anonymous` |
| GET | `/admin/v1/tasks` | 最近 100 个任务的 `agent_id`、`agent_name`、调用者、协议来源、`caller_ip`、状态与时间，不包含输入正文和模型密钥 |
| POST | `/admin/v1/tasks/{task_id}/cancel` | 请求取消后的任务 |
| GET | `/admin/v1/tasks/{task_id}` | 任务详情：`record`、`input`、`output`、`messages`、`tools`、`context`、`events`；仅管理员可读 |
| GET / POST | `/admin/v1/service-accounts` | 账号列表 / 创建账号并返回一次性凭据 |
| PATCH | `/admin/v1/service-accounts/{account_id}` | 启用、停用或更换凭据 |
| DELETE | `/admin/v1/service-accounts/{account_id}` | 删除账号、撤销凭据并清理所属历史与文件；任务未结束时返回 409 |

这些接口只接受管理员 Cookie。普通用户服务端口不暴露管理 API。采样在后台执行，HTTP 返回已采集的数据；重启后趋势重新开始，不作为长期监控或审计存储。

点击任务 ID 或“详情”，可以查看输入和附件信息、最终输出或错误、会话消息、工具参数与返回，以及运行事件。工具记录按本次 Run 过滤，打开详情不会重新加载模型或执行任务。未开始、失败或执行会话已经清理的任务仍可查看其保存的输入与事件；任务到期被清理后返回 `404`。运行事件沿用现有保留规则：最多 500 条，单条超过 16 KiB 的事件可能只有缩略信息，工具完整参数与结果从独立记录读取。

“上下文”展示已保存的会话摘要、保留消息与技能挂载；有配置快照的机器任务还展示提交时的 Agent 工作指引和下发技能内容。它不等同于每一次模型请求的原始报文：基础系统提示词、临时消息和完整模型请求没有持久化，旧任务没有保存的配置不会用当前配置冒充。详情不返回 Provider 密钥或服务账号凭据。
