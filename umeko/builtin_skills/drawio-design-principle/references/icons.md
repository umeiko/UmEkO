# 设计原理图图标表

图标是节点内的原生 draw.io 图元，支持离线编辑。用下列固定键填写
JSON 的 `icon` 字段。选择含义最贴切的一个，纯文字节点也可以留空。

| 键 | 可用于表达 | 原生图形 |
| --- | --- | --- |
| `input` | 外部输入、数据接收 | 平行四边形 |
| `output` | 结果、目标输出 | 梯形 |
| `process` | 运算、变换、执行 | 双竖线处理框 |
| `decision` | 条件判断、门控、比较 | 菱形 |
| `storage` | 持久化、缓存、状态库 | 圆柱 |
| `document` | 输入文档、规范、报告 | 文档 |
| `folder` | 文件集、材料集合 | 文件夹 |
| `cloud` | 外部服务、环境边界 | 云 |
| `measure` | 观测、探测、测量点 | 椭圆 |
| `rule` | 策略、约束、规则组件 | 六边形 |
| `component` | 物理部件、独立模块 | 立方体 |
| `trigger` | 触发、推进到下一状态 | 箭头形步骤 |
| `note` | 注释、设计说明 | 便签 |
| `card` | 单条记录、任务载体 | 卡片 |

参考上游按形状语义选择已知样式的做法，采用适合机制图的通用图形。
图中使用原生形状样式和文字。打开和导出无需下载图标文件。
