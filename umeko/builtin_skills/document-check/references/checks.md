# 文档审校清单

| 编号 | 检查内容 | 判断依据 |
| --- | --- | --- |
| D1 | 错别字、漏字、语句歧义和标点 | 引用原文，区分明确错误与可选措辞建议，不强改用户文风 |
| D2 | 术语、缩写、命名、符号与单位一致性 | 对照术语表、上下文及同一对象的其他表述；首次缩写无说明可给改进建议 |
| D3 | 数值、范围、默认值、必选/条件必选参数 | 对照提供的参数定义、表格与示例；只做有条件支撑的计算和一致性核对 |
| D4 | 步骤、输入输出、依赖条件和风险提示 | 检查先后关系、输入来源、输出去向、遗漏前置条件，以及高危操作说明是否自相矛盾 |
| D5 | 文内事实、图表、编号、章节及交叉引用 | 核对可读取的文内证据和提供的参考材料；缺少产品或版本依据时标待确认，不凭印象纠正 |
| D6 | 网址格式、可访问性与引用内容 | 通过 fetch_url 取得工具证据，分别记录访问结果和页面是否符合正文说明；受限/未读取不算通过 |

有依据的内容错误（如同一参数范围冲突、已证实的错误链接指向）列为“错误”；不改变事实的表达优化列为“建议”；缺少参照或网络受限列为“待确认”。

网址记录示例：

| 网址 | 位置 | 访问证据 | 内容核对 | 结论 |
| --- | --- | --- | --- | --- |
| https://docs.example.invalid/guide | §2 链接 | 工具报告 DNS_ERROR | 未取得页面 | 待确认；核对当前网络与地址 |

示例域名仅说明记录格式，不代表已访问。不要只按 HTTP 状态、域名外观或页面标题就认定所有内容正确；说明具体核对了哪些文字或条件。
