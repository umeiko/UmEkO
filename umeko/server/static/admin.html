统一管理智能体、接入方式和服务凭据。每个智能体通过 /agent/<name>/ 下的独立地址提供服务。

也可为程序或其他 Agent 创建独立凭据。带凭据调用的任务和文件按服务账号隔离；停用或更换后，旧凭据立即失效。

智能体地址包含用户服务的访问地址和部署前缀。生产部署请在 .env 设置 UMEKO_PUBLIC_URL，使 Agent Card 能返回完整外部地址。使用凭据时发送 Authorization: Bearer <服务凭据>；免鉴权调用可省略此项。
