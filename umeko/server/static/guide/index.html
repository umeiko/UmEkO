    UMEKO 使用手册¶

    这里面向工作台用户、平台管理员和服务接入方。文档随当前服务版本一起提供，可在内网直接阅读、搜索和复制示例，无需访问外网文档站。

    从你的工作开始¶

    你想做什么 从这里开始
    上传材料，让智能体处理文件或图片 工作台入门
    搭建模型、开放智能体、管理权限 管理员配置顺序
    让另一个程序或 Agent 调用服务 选择 REST、MCP 或 A2A
    了解任务、会话为什么不是一回事 会话与节点生命周期
    从机器任务转到浏览器中继续处理 临时工作台与接续
    查询报错、排队、文件和到期问题 常见问题与注意事项

    三个入口¶

    工作台用于日常对话和处理文件。管理控制台用于配置模型、智能体、技能、安全门禁和监控。机器服务用于程序、MCP 客户端和其他 A2A Agent 提交任务。

    管理员可能给不同入口设置不同域名或路径。本文示例使用 https://agents.example.internal/workbench 作为用户服务基址，reviewer 作为智能体路径名；实际地址以管理员提供的入口为准。Provider 的模型地址与这几个网页地址是不同的配置。

    文档适用范围

    截图使用合成的演示数据，不包含实际账号密码、模型密钥或用户文件。界面可能因权限、语言和所部署的版本略有差异。本手册不读取当前平台的用户数据，也不会自动执行示例请求。
