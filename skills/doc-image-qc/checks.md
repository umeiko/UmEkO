# 图片检查项清单（doc-image-qc 附属数据）

> 主 Agent 在阶段 2 派发每图质检任务时，从本清单选取适用检查项，
> 逐项写入子 Agent 任务描述；子 Agent 对每项给出结论。

## 通用检查项（所有图片）

| 编号 | 检查项 | 说明 |
|---|---|---|
| C1 | 图文一致性 | 图片内容与文中临近描述是否一致 |
| C2 | 图片质量 | 清晰度、文字可读性、构图完整性 |
| C3 | 敏感信息 | 公网 IP、版本信息、所有 IP、SNO/ESN、设备名称（如 DDM 左上角）、年月日、硬件编码、二维码 |

## 原理图类

| 编号 | 检查项 | 说明 |
|---|---|---|
| S1 | 原理图-描述一致性 | 原理图与原理描述逐点核对 |
| S2 | 流程正确性 | 流程步骤与操作步骤描述一致 |
| S3 | 分支完备 | 判断节点的分支标注完整、指向正确 |

## 组网图类

| 编号 | 检查项 | 说明 | 备注 |
|---|---|---|---|
| N1 | 组网图正确性 | 拓扑、连线、设备角色正确 | 风险点，受限模型能力，建议复测 |
| N2 | 组网图-描述一致性 | 与组网描述文字互相印证 | 同上 |

## 界面截图类

| 编号 | 检查项 | 说明 | 备注 |
|---|---|---|---|
| U1 | 界面截图正确性 | 截图与描述的实际操作界面一致，信息项不多不少 | |
| U2 | 界面-实际一致性 | 界面内容与真实产品界面核对 | 模型能力待验证 |
| U3 | 截图-步骤一致性 | 截图处于操作步骤描述的正确阶段；步骤点名的菜单/按钮/页签在截图中存在且名称逐字一致 | |
| U4 | 敏感信息（增强） | 在 C3 基础上逐项扫描截图内可见文本 | |
| U5 | 界面术语一致性 | 截图中菜单名、字段名、按钮文案、页签、单位符号（如 ℃）、专有名词与正文及实际界面用语逐字一致；术语不符（如"资讯"误作"信息"）、生造词、单位符号不规范均计入 | 术语与正文不符 = **FAIL**，不得降为 WARN |

## 用法

- 主 Agent 阶段 1 建清单时，根据图片上下文给每张图标注适用检查项分组
  （通用 / 原理图 / 组网图 / 界面截图，可多选）。
- 阶段 2 子 Agent 任务描述格式：
  「检查项：C1 图文一致（…）；N1 组网正确性（…）… 每项给出 PASS/WARN/FAIL
  与一句话依据」。
- **判定级别纪律**：事实性不一致（含术语与正文不符、步骤顺序错误、信息项多/缺）
  一律 FAIL；WARN 仅用于"确认存在但影响轻微"的问题（如措辞省略但语义完整、
  风格差异）。拿不准级别时按 FAIL 记并说明理由。
- 结论按检查项维度写入 qc-report.json（见主文档阶段 2 的 JSON 格式）。
