## 三个入口

**工作台**用于日常对话和处理文件。**管理控制台**用于配置模型、智能体、技能、安全门禁和监控。**机器服务**用于程序、MCP 客户端和其他 A2A Agent 提交任务。

管理员可能给不同入口设置不同域名或路径。本文示例使用 `https://agents.example.internal/workbench` 作为用户服务基址，`reviewer` 作为智能体路径名；实际地址以管理员提供的入口为准。Provider 的模型地址与这几个网页地址是不同的配置。

!!! note "文档适用范围"
    截图使用合成的演示数据，不包含实际账号密码、模型密钥或用户文件。界面可能因权限、语言和所部署的版本略有差异。本手册不读取当前平台的用户数据，也不会自动执行示例请求。
