# 工作台入门

工作台把对话、文件树和预览放在一起。登录方式与账号由管理员提供；通过机器任务返回的临时链接进入时，无需另外注册，使用范围和到期时间也不同。

## 完成一次文件任务

1. 新建或选择一个会话。
2. 将文件拖入文件树，或在输入框添加附件、粘贴剪切板中的图片。确认文件已出现在目录中，再发送任务。
3. 说明目标、检查范围和交付格式。例如：“检查附件中的流程图是否有断开的分支，输出问题清单。”
4. 任务执行时查看正在使用的工具；已完成工具收纳在调用历史中，点开可查看参数和返回结果。
5. 在文件树中选择产物预览，或使用下载按钮取得原文件。Markdown 可以切换渲染预览与原文。

## 文件放在哪里

| 目录 | 用途 |
| --- | --- |
| `attachments/` | 本轮上传或粘贴的附件 |
| `workspace/` | 工作材料、下载文件和处理中间资料 |
| `generate/` | 智能体生成的文件和交付件 |
| `client/skills/` | 本会话获准使用的技能副本 |

技能目录中的 Python 和配置等受保护文件只读；普通材料的读写仍受会话范围和工具权限约束。不要要求智能体操作服务器上的任意绝对路径。

## 选择模型与技能

普通工作台可在权限允许范围内选择主模型；视觉工具使用单独的视觉模型设置。管理员需要配置并开放对应模型。启用技能后，主模型先看到技能简介，再按需读取完整指引，不是每轮都重复附带所有技能全文。

会话里的技能是创建时下发的副本。管理员更新技能库后，已有会话不会自动变成新版；需要使用新版技能时新建会话。

## 下载链接也可以作为输入

需求里可以放普通 HTTP/HTTPS 文件链接。智能体会按任务需要尝试下载；是否能访问取决于文件权限、链接有效期以及管理员的网络和证书配置。无法取得关键材料时，智能体应说明缺什么、如何补齐，避免反复尝试同一个失败操作。

临时工作台的账号、新建会话和模型选择不可用；只能继续这个机器任务对应的会话。详见[临时工作台](integration/workspace.md)。
